## 🎯 نظرة عامة

**HARBI BOT** هو بوت تيليغرام متكامل يوفر نظام متجر ونقاط ومكافآت، مصمم خصيصاً للمستخدمين في سوريا. يمكن للمستخدمين جمع النقاط، استبدالها بمنتجات حقيقية (بطاقات شحن، اشتراكات، خدمات رقمية)، وتحويل النقاط بين بعضهم البعض.

### ✨ الميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| 🪙 **نظام النقاط** | كسب النقاط عبر المكافآت اليومية، الإحالات، أو الشراء |
| 💰 **رصيد البوت السوري** | نظام مالي متكامل بالليرة السورية |
| 🛒 **متجر متكامل** | 4 أقسام رئيسية، 15+ منتج متنوع |
| 📅 **مكافأة يومية** | 25 نقطة مجانية كل يوم |
| 👥 **نظام إحالة** | رابط فريد لكل مستخدم، مكافآت للدعوات |
| 💸 **تحويل النقاط** | تحويل النقاط بين أي مستخدمين |
| 🏆 **ترتيب (ليدر بورد)** | قائمة أغنى المستخدمين بالنقاط |
| 📜 **سجل العمليات** | تتبع كل معاملة ونقطة ورصيد |
| 👑 **لوحة تحكم الأدمن** | إدارة كاملة: إضافة نقاط/رصيد، حظر، إحصائيات |
| 📊 **إحصائيات متقدمة** | عدد المستخدمين، إجمالي النقاط، وأكثر |
| 🔒 **قاعدة بيانات SQLite** | أداء عالي وأمان وسرعة |
